# Sprint Planning 会议纪要模板

> Sprint：Sprint 【1/2/3/4】　|　日期：【YYYY-MM-DD】
> 主持：SM【名】　|　PO：【名】　|　参会：全员
> 实验对应：Lab 2（Sprint 1）/ Lab 4-5（Sprint 2）/ Lab 6（Sprint 3）/ Lab 8（Sprint 4）

---

## 一、Sprint 目标

- 一句话目标：**【本 Sprint 要达成的业务目标】**（如：完成问答核心闭环，可端到端提问/回答）

## 二、容量估算

- 团队历史 Velocity：**【上次完成 Story Points / 或首次预估】**
- 本 Sprint 计划容量：**【XX】 Story Points**

## 三、Sprint Backlog（任务分解与分配）

| 任务 ID | 关联故事 | 任务描述 | 预估(SP) | 责任人 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| T-01 | 【PB-xx】 | 【任务】 | 3 | 【成员】 | P0 |
| T-02 |  |  |  |  |  |

## 四、团队承诺

- 本 Sprint 团队承诺完成上述全部任务到 **DoD**。
- 明确"不接受范围蔓延"：Sprint 中新增需求放入 Product Backlog，不纳入本 Sprint（由 SM 监督）。

## 五、行动项 / 关注点

- [ ] 每 Task 完成即提 PR、走评审、合并
- [ ] 关键设计点提前咨询教师
