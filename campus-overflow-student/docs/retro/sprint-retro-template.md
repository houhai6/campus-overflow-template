# Sprint Retrospective 回顾纪要模板

> Sprint：Sprint 【1/2/3/4】　|　日期：【YYYY-MM-DD】　|　实验：Lab 6（示例对应 sprint-3.md）
> 主持：SM【名】　|　方式：☐ Start/Stop/Continue　☐ Sailboat
> 提交物示例：`docs/retro/sprint-3.md`

---

## 一、回顾模板

### 方式 A：Start / Stop / Continue

| 类别 | 内容 | 责任人 |
| --- | --- | --- |
| **Start**（开始做） | 【如：尽早做集成测试】 | 【成员】 |
| **Stop**（停止做） | 【如：在 main 上直接改代码】 | 全员 |
| **Continue**（继续做） | 【如：坚持先写测试】 | 全员 |

### 方式 B：Sailboat（帆船）

| 元素 | 说明 | 内容 |
| --- | --- | --- |
| 帆（推动前进） | 帮助团队成功的事 | 【如：清晰的 PR 评审流程】 |
| 锚（拖慢前进） | 拖累团队的阻力 | 【如：环境配置反复出问题】 |
| 礁石（潜在风险） | 尚未发生但危险 | 【如：联调接口后置】 |
| 小岛（目标） | 团队愿景 | 【如：Sprint 结束可演示核心功能】 |

| 【改进2】 | 【成员】 | 【如何判定生效】 | 【下个 Sprint】 |
